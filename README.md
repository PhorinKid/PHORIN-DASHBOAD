# PHORIN SNS 실측 대시보드

공개 진입점: index.html (GitHub Pages main/root).

매주 월·수·금 한국시간 오전 9시 실행에서 관측한 실제 수치를 날짜별 sns-data-YYYY-MM-DD.json으로 보관합니다. 누적·기간 수치와 당일 실적을 구분하며 미제공은 null입니다. 공식 API 실시간 연동은 없습니다.

2026-10-23·24·27·30 실제 관측 원본을 보존합니다. 더미 CSV·샘플 사진·내장 데모 데이터는 삭제했으며, 기존 데모 주소는 실측 대시보드로 이동합니다. 데이터가 없는 일반 소스는 보존하되 더미 생성 코드와 레거시 build 실행은 비활성화했습니다.

대시보드에서 날짜 선택, 콘텐츠 관측값, 전체 출처, JSON 다운로드를 지원합니다. 저장·공유·재게시를 구매전환으로 보지 않으며 집계기간이 다른 조회수를 합산하지 않습니다.

기본 지표 화면은 4개 채널의 팔로워·게시 항목·조회수·사용자 반응·댓글을 4행으로 요약합니다. 계정 단위의 관측값만 사용하며 누락된 계정 지표를 콘텐츠 누적 합계로 대체하지 않습니다. 전체 지표와 출처는 기본적으로 접힌 상세 보기를 펼쳐 확인할 수 있습니다.

전체 지표와 출처는 기본 페이지당 10개로 표시하며 15개로 변경할 수 있습니다. 현재 페이지를 중심으로 앞뒤 2개, 최대 5개의 번호 버튼을 표시하며 번호를 눌러 직접 이동할 수 있습니다. 처음·끝 구간에서는 범위를 조정해 가능한 한 5개를 유지합니다. 처음·이전·다음·마지막 이동도 지원합니다. 검색어, 관측일 또는 페이지당 항목 수를 변경하면 첫 페이지로 이동합니다. JSON 다운로드는 페이지 구분에 관계없이 선택 관측일의 전체 원본을 포함합니다. 화면의 모든 관측 데이터가 날짜별 원본 JSON과 일치하고 각 지표에 출처 URL이 있는지 테스트로 검증합니다.

## 로컬 실행

Node.js 20 이상에서 npm start를 실행하고 http://127.0.0.1:4173 을 엽니다. npm test로 목표와 페이지 기능을 검증합니다. 기존 npm run build는 제거했습니다. index.html이 실제 공개 소스입니다.
